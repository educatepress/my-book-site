## 2. ★出典と結論が逆になっていた記述（今回新たに発見。全件監査も拾えていない）

  「プロゲステロンの投与が流産予防に寄与する可能性（Haas DM, et al. 2025）」
  → 引用元は Cochrane（PMID 40497447）で結論は**効果はほとんどない**。9試験1,426名、
    流産率 RR 0.91(0.76-1.07)、生児獲得率 RR 1.04(0.96-1.12)。過去版には撤回された2試験が含まれていた

  「4周期を超える利益は限定的」という肝心の結論が落ちていた。数字をそのまま示す形に全面改稿

→ **型Gの検査（インライン引用と参考文献の照合）は、引用先が「実在するか」しか見ない。**

  （★the-skin-atelier の考え方どおり「**その弱さを本文で述べていれば通す**」形にした）

## ★移植した途端に見つかった誤り

`progesterone-early-pregnancy-miscarriage`（JP/EN 両方）

- 記事: 「原因不明の習慣性流産においては、経腟プロゲステロン製剤が有効であるという報告もあります」
- 実際: **効くのは「流産既往あり **かつ** 今回の妊娠で出血している」場合に限られる**

| 条件 | 結果 |
|---|---|
| 反復流産（出血なし） | 差なし RR 1.04 (0.95-1.15) 高確実性 |
| 出血あり・流産既往なし | 差なし RR 0.99 (0.95-1.04) 高確実性 |
| **流産既往1回以上＋出血あり** | **RR 1.08 (1.02-1.15)** / 75% vs 70% |
| **流産既往3回以上＋出血あり** | **72% vs 57%、RR 1.28 (1.08-1.51)** |
| 原因不明の反復流産（PROMISE 836名） | 有意差なし |
| 原因不明の反復流産（Cochrane 2025、9試験1,426名） | 差なし |

出典: PMID 33872382 / 32008730 / 40497447。**鍵は「今回の妊娠で出血しているか」**で、
そこを落とすと実際の根拠より広く聞こえる。JP/EN とも条件表の形に書き換えた。

→ **この誤りは、PMIDの実在検査でも、インライン引用の照合でも捕まらなかった。**
   台帳に「その論文の限界」を書き、それに触れているかを見る検査で初めて出た。
